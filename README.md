# E-Commerce Platform

A full-stack e-commerce platform built with Spring Boot, React, and PostgreSQL.

## Features

- User Authentication (JWT)
- Product browsing and searching
- Shopping cart management
- Order placement and checkout
- Responsive design

## Technology Stack

### Backend

- Java 17
- Spring Boot 3.1
- Spring Security with JWT
- Spring Data JPA
- PostgreSQL

### Frontend

- React 18
- React Router DOM v6
- Axios for API calls
- Tailwind CSS

### DevOps

- Docker & Docker Compose
- Maven

## Prerequisites

- Docker and Docker Compose
- Node.js (for local development)
- Java 17 (for local development)
